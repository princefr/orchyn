# Member profile

- The home page `/` shows the member's full name in `#name`, e.g. "Alice Chen".
- Below it, a "Tags" heading is followed by the member's tags, one per row in `#tags` (e.g. "admin", "beta").
- The profile is loaded from the server when the page opens; there is nothing to click.
- The page should show no error messages in the browser console.
