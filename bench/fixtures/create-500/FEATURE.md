# Todo list

- The home page `/` has a text field `#title` (placeholder "What needs doing?") and an "Add" button `#add-btn`.
- Clicking "Add" saves the typed text as a new todo on the server via `/api/todos`.
- After saving, the list `#list` shows every todo the server has, in the order they were added.
- Blank input is ignored and nothing is sent.
- The field is cleared after each Add.
