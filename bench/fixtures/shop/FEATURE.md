# Shop items

- The home page `/` shows the shop's catalogue as a list `#items` titled "Shop items".
- The list is loaded from the server when the page opens.
- Each catalogue entry appears as one list row with its name, e.g. "Apples" and "Bread".
- If the catalogue is empty or cannot be loaded, the list shows a single row reading "No items".
- The list is read-only; there is nothing to click.
