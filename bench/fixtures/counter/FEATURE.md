# Shared counter

- The home page `/` shows a single shared counter with the text "Count: N" in `#count`.
- The count is kept on the server, so every visitor sees the same value.
- When the page loads it shows the current value from the server.
- The button labelled "Increment" (`#inc`) adds one to the count and shows the value the server returns.
- Each click sends one increment; the page never changes the count on its own.
